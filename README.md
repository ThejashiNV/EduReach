**EduReach – School Donation and Volunteer Platform
**
EduReach is a full-stack web application designed to connect rural students with donors and volunteers. The platform helps provide educational resources such as books, stationery, and mentorship opportunities to underserved communities.

**Features**
Student registration and profile management
Book and stationery donation requests
Volunteer registration and coordination
Donor dashboard to track contributions
Responsive and user-friendly interface
Secure backend APIs and database integration
**Tech Stack**
**Frontend**
HTML
CSS
JavaScript
**Backend**
Node.js
Express.js
**Database**
MySQL
Design
Figma

**Project Objective**

The goal of EduReach is to bridge the educational gap for rural students by making it easier for donors and volunteers to contribute resources and support.

**Modules**
Student Module

Students can create requests for books and educational materials and connect with volunteers for academic guidance.

**Donor Module**

Donors can view student requests and contribute books or other resources.

**Volunteer Module**

Volunteers can register to provide tutoring, mentoring, and educational assistance.

**Admin Module**

Administrators manage users, monitor requests, and coordinate platform activities.

**Installation**
git clone <repository-url>
cd EduReach
npm install
npm start
